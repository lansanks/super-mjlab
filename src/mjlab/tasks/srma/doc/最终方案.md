# SRMA 最终方案

> 状态：方案定稿，尚未实现。
>
> 日期：2026-10-18。
>
> 目标文件：`src/mjlab/tasks/srma/doc/最终方案.md`。

## 0. 一句话概括

SRMA 借鉴 RMA 的“特权教师 + 在线适应学生”思路改造 DreamWaQ：第一阶段让 actor
使用真实速度和由局部地形、摩擦、上一时刻外力编码出的 16 维外部 latent 学出强策略；
第二阶段冻结教师，用学生自己的 on-policy 轨迹做 DAgger，让学生仅凭可部署的本体历史
同时估计速度与外部 latent，并训练新的学生 actor。学生不使用 CENet 的 VAE 重建目标，
不直接使用足端接触、滞空时间、高度图或摩擦。

## 1. 动机与目标

DreamWaQ 原有 CENet 通过重建下一帧本体观测学习 16 维 latent。已有实验表明：

- 速度和任务跟踪可以学到，但 latent 更容易编码步态相位、身体状态等快变量；
- 仅用 t-SNE 是否按地形聚类来评价 latent 不够，且不能证明 latent 对控制有用；
- 环境随机的摩擦、地形等外部因素才是希望被快速适应的主要对象。

RMA 的关键启发是：不需要重建完整环境或估计真实物理参数，而是先学习一个能改善控制
的低维特权 latent，再蒸馏成只依赖历史的在线估计。

本方案的目标是：

1. 用仿真特权信息训练一个对控制直接有用的 16 维外部环境 latent；
2. 用 stateful GRU 从本体历史在线估计速度和外部 latent；
3. 用 DAgger 蒸馏出新 actor，而不是直接冻结教师 actor 后硬切换输入；
4. 部署时完全不依赖高度图、摩擦、真实速度或外力。

## 2. 核心口径

| 项目 | 最终决定 |
| --- | --- |
| 机器人/环境 | 先基于 Go1 rough velocity 任务实现 |
| 教师外部信息 | 身体下方局部高度图、足底摩擦、上一时刻外力 |
| 教师 actor 输入 | `[o_t(45), v_gt(3), l_teacher(16)]`，共 64 维 |
| 学生 actor 输入 | `[o_t(45), v_hat(3), l_hat(16)]`，共 64 维 |
| 学生时序上下文 | 50 个控制步，50 Hz 下约 1 秒 |
| 学生时序模型 | hidden=64 的 stateful 单层 GRU |
| 外部 latent | 16 维，经过 LayerNorm |
| 第二阶段 | 学生估计器预训练 + DAgger 训练新 actor |
| 部署 | 只运行 stateful GRU 和学生 actor，与 50 Hz actor 同步 |
| 已删除信息 | VAE 解码器、下一帧观测重建、contact、air time、足端高度 |

这里不把四足接触状态和滞空时间放入教师或学生输入。硬件部署时无法稳定获得这些信号，
并且它们变化快，放入外部 latent 容易重新引入步态相位。

### 2.1 代码审查后的实现约束

基于当前 DreamWaQ、mjlab 和 RSL-RL 5.5.1 代码，以下约束已经确认：

1. 教师阶段使用基础 `PPO`，不能复用 `DreamwaqPPO`，因为后者强绑定 VAE、AdaBoot
   和 `DreamwaqActorModel`。
2. 学生使用 stateful GRU。当前 `RolloutStorage` 会逐步复制完整 observation group，
   固定 50 帧窗口在 4096 env 下约产生 844 MiB 单份历史存储。
3. RSL-RL 的 `Distillation` 只能作为骨架。它当前只做动作 MSE、只使用 student action、
   不含 latent/速度损失，也未接入 mjlab runner。
4. 教师的局部高度图、support normalization、上一时刻 push 和 friction 都需要新增
   observation term，不能直接复用现有 critic height scan。
5. 教师和学生必须注册成两个独立任务，分别使用 PPO、DAgger/播放配置。

## 3. 符号

- `o_t`：45 维可部署本体观测，沿用 DreamWaQ actor 观测：
  角速度、投影重力、关节位置、关节速度、上一动作、速度指令。
- `v_t`：仿真真值基座线速度，3 维。
- `H_t`：机身下方的局部地形高度图。
- `f`：足底摩擦参数，3 维。
- `d_{t-1}`：上一控制步施加的外力/速度冲击，机身系 6 维。
- `l_t`：教师外部编码器输出的 16 维 latent。
- `v_hat_t, l_hat_t`：学生从本体观测和 GRU hidden state 估计出的速度和外部 latent。
- `pi_T`：第一阶段特权教师 actor。
- `pi_S`：第二阶段新训练的学生 actor。

## 4. 教师外部信息

### 4.1 局部地形高度图

地形图覆盖机身下方的小范围区域，不覆盖完整周围环境，也不只限制在当前接触脚附近。

初始网格：

```text
x: -0.25 ~ +0.25 m
y: -0.20 ~ +0.20 m
分辨率: 0.05 m
网格: 11 x 9
高度值数量: 99
```

坐标口径：

- 水平网格以机身中心为原点；
- 只按 yaw 对齐，不随机身 pitch/roll 旋转；
- 高度沿世界竖直方向采样；
- 不使用世界绝对位置或绝对高度作为网络输入。

垂直归一化参考使用支撑脚高度的中位数，而不是机身中心高度：

```text
z_ref = median(world_z of contact feet)
h_norm(i, j) = clip((h_world(i, j) - z_ref) / 0.15, -3.0, 3.0)
```

理由：

- 水平坐标已经以机身为中心，空间关系是自车相对的；
- 垂直方向减去支撑高度可以去掉机身起伏，使 latent 更关注地形本身；
- 相对机身中心会把身体上下运动、pitch/roll 等状态混入高度图，容易再次编码相位和躯体状态。

边界条件：

- 至少一只脚接触时，取接触脚高度中位数；
- 四脚腾空时，沿用上一控制步的 `z_ref`；
- 不建议拟合倾斜平面，因为双脚踩在不同高度台阶时会产生错误倾斜；
- 若 `z_ref` 在触地切换时跳变明显，可加入轻微低通，但训练和部署标签口径必须一致；
- 无效或未命中单元格使用 0 和可选 mask，具体在实现时二选一，不能混用。

现有 DreamWaQ 的 `terrain_scan` 是 `1.6 x 1.0 m`、`0.1 m` 分辨率，且 `height_scan`
返回相对 trunk 的 clearance，不能直接生成上述地图。SRMA 需要：

- 新增独立的 `srma_teacher_scan` raycast sensor，保持现有 critic 扫描不变；
- 使用 class-based observation term 维护每环境的 `z_ref` 和 reset 状态；
- 从 `hit_pos_w.z` 获取世界高度；
- 从 `feet_ground_contact.found` 和足端 site 世界位置计算支撑高度中位数；
- 输出展平的 `(B, 99)`，在 actor 内 reshape 为 `(B, 1, 11, 9)`。

新增 99 条 ray 相对现有 187 条地形 ray 会增加约 53% 的 terrain raycast 数量，必须在
4096 环境配置下测一次 FPS。

### 4.2 足底摩擦

当前 Go1 环境对全部足底 geom 共享摩擦随机化，使用 3 个轴：

```text
mu_slide
mu_spin
mu_roll
```

由于 spin/roll 跨多个数量级，编码前使用对数：

```text
f = [
  log(mu_slide),
  log(mu_spin),
  log(mu_roll),
]
```

再做固定范围裁剪或 running normalization。摩擦只在教师外部编码器中使用，学生通过本体
响应估计它。

### 4.3 上一时刻外力

使用现有的 push 记录，时间索引明确为 `d_{t-1}`：

```text
d_{t-1} = [
  delta_vx, delta_vy, delta_vz,
  delta_wx, delta_wy, delta_wz,
]
```

该量位于机身系。只使用上一时刻而不是当前时刻，避免教师获得学生不可能及时获得的
前馈信息。

现有 DreamWaQ 的 `push_velocity` 是“最近一次非零 kick”，会保持到下一次 push 或
episode 结束，不能直接作为 `d_{t-1}`。SRMA 必须新增独立的 `previous_push_velocity`
观测：

- event 额外记录 `last_push_step`；
- observation 仅在 `current_step - last_push_step == 1` 时返回 kick；
- 下一控制步返回零；
- episode reset 时清除记录。

### 4.4 明确排除的信息

以下信息不进入教师外部编码器，也不进入学生 actor：

- 四足 contact；
- foot air time；
- 足端 clearance；
- 周围完整高度图；
- 全局位置、全局地形坐标；
- 地形类别 one-hot；
- payload、质心、电机强度。它们继续由域随机化覆盖，首版不做显式适应；
- 当前时刻外力。

地形类别可以在实验分析中作为标签，但不能作为控制训练目标。

## 5. 第一阶段：特权教师

### 5.1 数据流

```text
局部高度图(11 x 9)
        |
       CNN ----\
                +--> 外部编码器 --> l_teacher(16) --> LayerNorm
摩擦(3) --------/
外力(6) --------/

[o_t(45), v_gt(3), l_teacher(16)]
        |
   教师 actor
   64 -> 512 -> 256 -> 128 -> 12
        |
       a_t
```

### 5.2 外部编码器结构

建议初始结构：

```text
height map 1 x 11 x 9
  -> Conv2d(1, 16, kernel=3, padding=1) + ELU
  -> Conv2d(16, 32, kernel=3, stride=2, padding=1) + ELU
  -> Flatten
  -> Linear(64)

[friction(3), prev_push(6)]
  -> Linear(32) + ELU

concat(height_feature(64), vector_feature(32))
  -> Linear(64) + ELU
  -> Linear(16)
  -> LayerNorm(16)
```

外部编码器是教师 actor 的子模块，和 actor 共用第一阶段的 PPO 优化器。

### 5.3 `l_teacher` 的语义

`l_teacher` 不要求还原高度图、摩擦或外力，也不要求按地形类别聚类。它只要求成为对
教师控制有用的低维条件向量。加入 LayerNorm 的目的是稳定教师与学生 latent 的尺度，
避免直接 MSE 被任意尺度和少数维度主导。

第一版不额外加入重建损失。外部编码器只接收 PPO 梯度，这保留了 RMA 中“latent 从
控制目标中出现”的思想。

### 5.4 PPO 配置

第一阶段直接使用 RSL-RL 基础 `PPO`，不能复用 DreamWaQ 的 `DreamwaqPPO`。后者强绑定
VAE、重建损失、AdaBoot 和 `DreamwaqActorModel`。基础 PPO 的优化器会包含教师 actor
内部的外部编码器，因此无需额外算法类。

首版沿用当前 HIM/mjlab 的稳定训练口径，并保持与既有 Go1 rough 实验可比：

```text
seed: 42
num_envs: 4096
num_steps_per_env: 24
max_iterations: 3000
num_learning_epochs: 5
num_mini_batches: 4
learning_rate: 1e-3
schedule: adaptive
desired_kl: 0.01
gamma: 0.99
lam: 0.95
clip_param: 0.2
entropy_coef: 0.01
max_grad_norm: 1.0
```

训练预算为初始值。若最近 300-500 轮内回报、地形课程和跟踪指标均无实质提升，可提前
停止教师训练。

### 5.5 第一阶段必须通过的检查

第一阶段不是只看总回报。至少检查：

1. 教师策略是否达到或超过当前 DreamWaQ/velocity 基线的运动质量；
2. `teacher no external`、`teacher map`、`teacher map + friction`、
   `teacher map + friction + force` 的差异；
3. latent 各维是否有有效变化，不能全部塌缩到常数；
4. 将 `l_teacher` 置零或打乱后，教师动作和成功率是否明显下降；
5. 在相同地形等级和固定指令下比较，避免课程进度混淆。

如果外部信息教师没有优于无外部信息教师，应停止第二阶段，先检查外部信息或奖励设计，
不能把学生蒸馏当作补救手段。

### 5.6 第一阶段代码实现路径

教师模型建议命名为 `SRMATeacherActorModel`，继承 `MLPModel`：

- 在 `super().__init__()` 前解析外部观测组和 latent 维度；
- 覆写 `_get_latent_dim()`，返回 `45 + 3 + 16 = 64`；
- 覆写 `get_latent()`：
  1. 用 `super().get_latent()` 得到归一化后的 `o_t(45)`；
  2. 读取并 reshape 局部高度图；
  3. 编码高度图、摩擦和上一时刻外力；
  4. LayerNorm 得到 `l_teacher(16)`；
  5. 返回 `cat([o_t, v_gt, l_teacher])`；
- 不 detach `l_teacher`，确保 PPO 梯度进入外部编码器；
- 覆写 `as_onnx()`；教师 ONNX 只用于内部检查，不作为最终部署模型。

新增配置字段建议：

```text
RslRlModelCfg.srma_cfg:
  latent_dim
  height_group
  height_shape
  friction_group
  push_group
  velocity_group
  height_encoder_cfg
  vector_encoder_cfg
```

`MjlabOnPolicyRunner` 的 None 清理逻辑需要把 `srma_cfg` 加入可选字段列表。

第一阶段任务注册建议：

```text
Mjlab-SRMA-Teacher-Rough-Unitree-Go1
```

该任务只训练教师 actor 与 critic。教师 checkpoint 的 `actor_state_dict` 中必须包含
MLP、normalizer、distribution 和 external encoder。

SRMA teacher 环境独立提高课程地形上限：`pyramid_stairs` 与
`pyramid_stairs_inv` 的 `step_height_range` 均为 `(0.0, 0.25)`，即最高 25 cm。
该修改使用 terrain config 的 deep copy，不影响 DreamWaQ 或其他任务。

训练时必须发布以下 teacher 诊断到 `Metrics/`：

- `srma_latent_effective_rank`：协方差特征值计算的参与率；
- `srma_height_map_std`；
- `srma_friction_std`；
- `srma_push_fraction`；
- `srma_action_delta_zero`、`srma_action_delta_shuffle`；
- `srma_external_grad_norm`。

## 6. 第二阶段学生估计器

### 6.1 输入

学生估计器只使用部署可获得的 45 维本体观测：

```text
o_t
```

不输入 contact、air time、足端高度、高度图、摩擦或外力。

时间上下文由 stateful GRU 保存。每个 DAgger rollout 固定采集 50 个控制步，对应
50 Hz 下约 1 秒。hidden state 在每个 episode reset 时清零，禁止跨 episode 传播。

### 6.2 网络

```text
o_t(45)
  -> Linear(64) + ELU
  -> GRU(hidden=64, num_layers=1)
  -> h_t
       |-> Linear(3)  -> v_hat
       |-> Linear(16) -> LayerNorm(16) -> l_hat
```

初始默认：

```text
frame_dim = 45
hidden_dim = 64
latent_dim = 16
student_rollout_steps = 50
reset_hidden_on_done = True
```

GRU hidden 128 作为后续消融。第一版使用 stateful GRU，而不是为每个 transition
重复保存 50 帧窗口。这样训练时每个观测只处理一次，部署时仍然与 actor 同步运行。

### 6.3 观测归一化

- 45 维 actor 观测量沿用 running `EmpiricalNormalization`；
- 教师 `l_teacher` 和学生 `l_hat` 都经过 LayerNorm；
- 速度回归使用原始单位，指标保持 m/s。

### 6.4 recurrent replay

学生模型应实现与 `RNNModel` 一致的 recurrent 接口：

```text
is_recurrent = True
get_hidden_state()
reset(dones)
detach_hidden_state()
```

第二阶段训练按时间顺序 replay。梯度截断长度初始设为 25 步，即约 0.5 秒。一次完整
rollout 为 50 步，训练结束时保存 hidden state，供下一轮 rollout 延续；episode done
时在对应环境上清零。

### 6.5 代码实现路径

新增 `SRMAStudentActorModel`，同时包含 GRU 估计器和策略 MLP：

- `_get_latent_dim()` 返回 `45 + 3 + 16 = 64`；
- `get_latent()` 用当前 `o_t` 更新 GRU，生成 `v_hat/l_hat` 后与 `o_t` 拼接；
- `v_hat/l_hat` 在 actor 路径上 stop-gradient；
- `reset(dones)` 调用 GRU 的 per-env hidden reset；
- 暴露 `last_estimator_output` 供自定义 Distillation 计算 latent 和速度损失；
- `as_onnx()` 输出 action 与 `h_out`，并显式接收 `h_in`。

第二阶段的 loss 必须只训练学生参数；教师 actor 和教师外部编码器始终冻结并保持 eval。

## 7. 学生 actor

学生 actor 与教师 actor 完全同构：

```text
[o_t(45), v_hat(3), l_hat(16)]
-> 512 -> 256 -> 128 -> 12
```

学生 actor 从教师 actor 权重初始化。DAgger 阶段只监督动作均值，不要求匹配教师动作
标准差。部署时使用确定性动作均值。

## 8. 第二阶段训练协议

### 8.1 冻结范围

第二阶段冻结：

- 教师 actor `pi_T`；
- 教师外部编码器 `Enc_e`；
- 教师 latent 的 LayerNorm。

只更新：

- 学生 GRU；
- 学生 `v_hat` 和 `l_hat` 输出头；
- 学生 actor `pi_S`。

### 8.2 阶段 2A：学生估计器预训练

先运行教师策略 30-50 轮，用教师的真值速度和 latent 预训练学生 GRU：

```text
L_pretrain = L_v + L_l
```

每轮规模：

```text
4096 envs x 50 steps = 204,800 transitions
```

目的：

- 让学生在 actor 蒸馏开始前具备基本可用的 `v_hat/l_hat`；
- 避免 DAgger 前几十轮主要在学习随机估计器噪声；
- 给新 actor 一个接近教师输入分布的初始环境。

### 8.3 阶段 2B：DAgger

每轮流程：

1. 用当前学生 actor 和 GRU 收集 on-policy 轨迹；
2. 在学生访问到的每个状态上，用冻结教师计算
   `l_teacher = Enc_e(e_t)` 和 `a_teacher = pi_T(o_t, v_gt, l_teacher)`；
3. 教师标签和训练观测使用同一个 `o_t`，教师额外获得真值速度和外部 latent；
4. 更新学生 GRU 和学生 actor；
5. 重复，逐步提高学生自身状态占比。

教师动作使用动作均值作为目标，不能使用教师 rollout 中随机采样的单个动作。

### 8.4 数据配比

以环境实例为单位混合教师和学生动作，不在一条 episode 内随机切换：

| DAgger 轮次 | 教师动作轨迹 | 学生动作轨迹 |
| --- | ---: | ---: |
| 1-20 | 50% | 50% |
| 21-50 | 25% | 75% |
| 51-150 | 0% | 100% |

无论轨迹由教师还是学生产生，状态都由教师重新打动作和 latent 标签。

### 8.5 损失函数

先对速度和动作误差做尺度归一化，使三个损失处于可比量级：

```text
sigma_v = running_std(v_gt), clamp_min=0.1
sigma_a = running_std(a_teacher), clamp_min=0.05

L_v = mean(((v_hat - v_gt) / sigma_v)^2)
L_l = mean((l_hat - l_teacher)^2)
L_a = mean(((mean(pi_S) - mean(pi_T)) / sigma_a)^2)

L = L_v + lambda_l * L_l + lambda_a * L_a
```

初始值：

```text
lambda_l = 1.0
lambda_a = 1.0
```

教师 latent 和教师动作都使用 stop-gradient。

### 8.6 优化设置

初始建议：

```text
optimizer: Adam
learning_rate: 5e-4
learning_epochs_per_round: 4
gradient_length: 25
max_grad_norm: 1.0
max_dagger_rounds: 150
```

每轮 204,800 条 transition。支持根据验证集动作误差、latent 误差和固定地形成功率提前
停止。

### 8.7 Distillation 代码路径

RSL-RL 自带的 `Distillation` 只能作为骨架。当前实现只计算 student/teacher 动作 MSE，
rollout 始终使用 student action，并且没有 mjlab runner 注册。SRMA 需要新增
`SRMADistillation`：

- rollout 时按环境分配 teacher/student action；
- teacher 持续 eval 且 `requires_grad=False`；
- student 前向同时暴露 `v_hat/l_hat`；
- update 时联合计算 `L_v/L_l/L_a`；
- 按时间顺序 replay stateful GRU，并在 done 处重置 hidden state；
- 支持 stage 2A 只优化估计器、stage 2B 联合优化 actor 和估计器；
- save 同时保存 teacher/student，最终 play 只加载 student。

新增 `SRMADistillationRunner`，继承或参考 `MjlabOnPolicyRunner`，负责 teacher
checkpoint 自动加载、环境计数器和 ONNX 导出。RSL-RL `DistillationRunner` 不能直接注册，
因为它不包含 mjlab 的 checkpoint、metadata 和 play-path 行为。

### 8.8 是否加入 PPO

第一版保持纯 DAgger，不同时做 PPO。若满足以下任一条件，再增加 100-300 轮小学习率
PPO 微调作为独立消融：

- actor 动作误差已经较低，但闭环成功率仍明显低于教师；
- 学生估计器误差稳定，但策略对估计噪声过于敏感；
- 纯 DAgger 在分布外地形上明显退化。

PPO 微调阶段冻结教师外部编码器，建议学习率 `1e-4` 到 `3e-4`。

## 9. 部署接口

部署时只保留：

```text
o_t(45), h_in(1, 64)
        |
     stateful GRU
        |
[v_hat(3), l_hat(16)], h_out(1, 64)
        |
学生 actor
        |
12 维期望关节角
```

不运行教师 actor、外部编码器、高度图 raycast、friction lookup 或外力记录。

运行频率：

```text
GRU 与学生 actor: 50 Hz，同步
训练 rollout 上下文: 50 个控制步，约 1.0 s
部署持久状态: h_t(64)
```

部署端只需要保存 64 维 float32 hidden state。episode 开始时重置为 0，环境 reset 时
对应机器人清零。

本机 CPU 微基准中，stateful 单层 GRU 加 actor 的一次 batch=1 更新约 0.07 ms；
50 帧序列重复前向约 0.47 ms。实际机器人性能仍需在目标板载计算上测量，控制周期预算
为 20 ms。

## 10. 训练数据与存储

第一版不把 50 帧窗口作为 observation group 存入 rollout storage。

当前 RSL-RL `RolloutStorage` 会为每个 transition 复制完整 observation group。如果
仍使用 `50 x 45` 历史组：

```text
50 x 45 x 4096 envs x 24 steps x 4 bytes
≈ 844 MiB / 份
```

这还没有计算其他观测、教师特权信息、动作和临时张量，而且每一步都要重复对 50 帧顺序
前向。

最终采用：

- rollout 只保存当前 `o_t(45)`；
- 学生模型内部保存 per-env `h_t(1, 64)`；
- 训练按时间顺序 replay，并在 done 处 reset hidden state；
- teacher/student action labels 和 `v_gt/l_teacher` 按 transition 保存或由冻结教师重算。

RSL-RL 的 RL storage 已支持 hidden state 保存和 recurrent minibatch。学生 DAgger
使用自有 sequential replay，不依赖默认 feedforward minibatch shuffle。

建议新增的教师专用观测组：

```text
teacher_height_map       (B, 99)，actor 内 reshape 为 (B, 1, 11, 9)
```


`teacher_height_map` 的归一化需要当前接触脚高度中位数，但 contact 本身不会进入任何

还需要新增：

```text
srma_teacher_scan sensor:
  size=(0.5, 0.4), resolution=0.05, ray_alignment="yaw"
```

## 13. 评测矩阵

### 13.1 教师消融

| 臂 | 外部输入 |
| --- | --- |
| T0 | 无外部信息，只使用 `v_gt` |
| T1 | `v_gt + local height map` |
| T2 | `v_gt + local height map + friction` |
| T3 | `v_gt + local height map + friction + prev push` |

目的：确认每类特权信息是否真的改善教师控制和鲁棒性。

### 13.2 学生消融

| 臂 | 说明 |
| --- | --- |
| S0 | 原 DreamWaQ β=0.04 |
| S1 | 学生速度估计 + DAgger，但 `l_hat` 置零或不输入 |
| S2 | 学生完整 `v_hat + l_hat` |
| S3 | 使用教师 `v_gt + l_teacher` 的教师上界 |

如果需要，再增加：

- 学生 GRU hidden 64 vs 128；
- GRU rollout horizon 25 vs 50；
- 有 friction vs 无 friction；
- 纯 DAgger vs DAgger + 少量 PPO。

### 13.3 固定评测

训练曲线只用于过程监控，结论必须来自固定口径评测：

- 固定地形等级 3 和 5；
- 固定命令序列和扰动 seed；
- 相同 teacher、student、DreamWaQ 初始化；
- push 1x-4x；
- 摩擦、台阶高度、局部高度图的训练内和训练外范围；
- 至少 2-3 个训练 seed，条件允许时优先 3 个。

### 13.4 指标

策略指标：

- reward；
- episode length；
- illegal contact / falls；
- terrain level；
- linear/angular tracking error；
- peak joint velocity；
- 固定扰动下的 survival。

估计指标：

- `Metrics/velocity_est_error`，单位 m/s；
- `MSE(l_hat, l_teacher)`；
- 可选 cosine similarity；
- 学生与教师动作均值的闭环误差。

latent 指标：

- 每维 running std 和有效 rank；
- teacher latent 置零、打乱、替换成其他环境 latent 后的动作变化；
- 学生 latent 与教师 latent 在固定状态上的差异；
- t-SNE 只做可视化，不作为主要结论。

一个有用的行为测试是：

```text
同一 o_t、同一 v，
分别输入 teacher l、student l_hat、零 latent，
比较 actor 输出动作和后续闭环表现。
```

这比单纯检查 latent 是否按地形聚类更接近“latent 是否被策略使用”。

### 13.5 实现级测试

实现阶段至少覆盖：

- 局部高度图形状、support normalization 和 episode reset；
- 四脚腾空时 `z_ref` 保持；
- `previous_push_velocity` 只在 push 后下一控制步非零；
- 教师 PPO 梯度进入 external encoder；
- latent 置零和 shuffle 后教师动作改变；
- student hidden state 在 done 处重置；
- student actor 从 teacher actor MLP 权重初始化；
- teacher 参数在 DAgger 中无梯度；
- `L_v/L_l/L_a` 有限且能反传到对应模块；
- teacher/student 轨迹配比；
- stateful ONNX 的 `obs/h_in -> actions/h_out` 和 hidden reset。

## 14. 风险与回退方案

### 14.1 教师依赖未接触地形

局部高度图包含摆动脚尚未接触的区域。教师可能有轻微提前预判，学生只能通过历史事后
适应。

应对：

- 比较 `teacher no map` 和 `teacher map`；
- 若学生始终落后，限制高度图只保留机身中心附近，或降低前向覆盖；
- 不把完整周围地图加入首版。

### 14.2 摩擦或高度 latent 不可辨识

学生可能只能学习环境分布的平均值。

应对：

- 延长 student rollout / TBPTT horizon 到 75/100 步做消融；
- 在训练中增加包含明显打滑或台阶响应的课程；
- 检查学生 latent 是否是常数，而不是只看动作最终是否可走。

### 14.3 latent 塌缩

如果 `l_teacher` 被 actor 忽略，PPO 可能学出接近常数的 latent。

应对：

- 监控每维 std 和有效 rank；
- 做 `l = 0`、shuffle latent 的教师动作敏感性测试；
- 必要时加入轻微 variance/covariance 正则，但不加入完整重建损失。

### 14.4 DAgger actor 过拟合

如果学生只模仿当前轨迹，闭环后仍可能偏离。

应对：

- 保持 on-policy 重新收集；
- 逐步提高学生轨迹比例；
- 增加教师坏状态和恢复状态；
- 最后才考虑 PPO 微调。

### 14.5 GRU 训练成本过高

已经选择 stateful GRU，不再保存固定 50 帧窗口。仍需监控：

- 50 步 rollout 的 recurrent replay 吞吐；
- 25 步 TBPTT 的显存；
- hidden state 在 done 处是否正确重置；
- 多轮 update 后 hidden state 是否错误累积跨 episode 信息。

## 15. 成功判据

首版实现完成后，至少满足：

1. 教师 T3 在固定评测中不弱于无外部信息的 T0，且在至少一个外部扰动维度上更强；
2. 学生 stateful GRU 能稳定估计速度，速度误差接近原 DreamWaQ CENet 的量级；
3. 学生 DAgger 后的闭环 reward、生存率和跟踪误差接近教师；
4. 学生 latent 不是常数，置零或替换后动作和闭环性能会下降；
5. 学生部署接口只依赖 45 维本体历史；
6. 固定扰动下学生不弱于 DreamWaQ，且至少在摩擦、台阶或外力中的一类分布外条件上更好。

如果学生性能接近教师但没有任何外部信息敏感性，说明蒸馏只学到了速度和普通步态，
不能宣称学会了外部环境 latent。
