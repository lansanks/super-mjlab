# 视觉学生抗噪机理判断（工作假设）

> 状态：基于训练代码与部署侧噪声实验的理解，**未做因果 ablation**。
> 实验数据与图：`deploy/test/灵敏性分析.md`（同步版见 `视觉学生抗噪灵敏性分析.md`）。
> 这里只解释“训练没加深度噪声，为什么对 pixel 级退化仍较稳”，不声称对所有 corruption 免疫。

## 1. 一句话

深度不是被“清洗”得抗噪，而是被训练成一个**低维、平滑的地形估计器**：

```text
160×90×2
  -> 15 格 × 32
  -> 64-D
  -> visual GRU(64)
  -> 16-D height latent
  -> actor（连同 45-D 本体 + 3-D 速度 + 6-D 特权）
```

它的监督目标是教师 187 点 height map 的 latent，而不是像素或动作。随机 pixel 噪声很难把这个 16-D 表示推到另一个“盆地”；GRU 再在时间维平滑一次。

## 2. 准确的因果链

1. **教师**：187 点 height map（1.6×1.0 m，0.1 m）→ 16-D height latent；friction/push → 6-D privilege latent；actor 输入 70 维。
2. **学生**：深度 + 本体 → 双 GRU → 估计 16-D height、6-D privilege、3-D velocity；三段估计 **detach** 后进 actor（`visual_student_actor.py`）。
3. **深度链路**（`visual_student_actor.py`）：
   - Conv 5×5/3×3/3×3（stride 2）→ 20×12×32；
   - `AdaptiveAvgPool2d(3,5)` → **15 格 × 32**（3 行×5 列，每格约 32×30 原图像素）；
   - flatten 480 → Linear **64-D** → visual GRU **64** → **16-D height latent**。
   - 深度只占 actor 输入的 **16/70**；其余 54 维是本体/特权/速度。
4. **预处理**（`student_depth_image`）：
   - 0.3–4.0 m clip + 归一化；
   - `valid = isfinite & 0.3<=d<=4.0`；无效像素 depth=0、**mask=0**；
   - 输入是 2 通道；mask 让网络区分“洞”和“0.3 m 近墙”；
   - 25 Hz 更新（`camera_update_period=2`）。
5. **GRU**：25 Hz 深度 + 64 维 hidden，时间上平滑单帧突变；地形信念可跨帧保持。
6. **训练**：DAgger 教师比例 1.0→0.2；latent/velocity loss 训练两个 GRU，action loss 只更新 actor；学生越来越多地在自己的状态分布上被纠正。

## 3. 对“盆地”的准确说法

- 16-D latent 是**连续**的，不是“几种离散运动模式”；
- “同一盆地”指：小扰动下 latent 只在小范围移动，actor 输出仍在原 gait/决策附近；
- 20% Perlin 已能把 s1 推出盆地（卡在 1.32 m）；
- 外参 3°/2cm、大块无效 30–40% 会直接换盆地（0/4）。

## 4. 为什么“没有深度噪声训练”也能抗

- 监督目标是低维、平滑的 height latent，不是像素重建；像素细节是 nuisance；
- 15 格池化 + 64-D + 16-D 是强信息瓶颈，高频噪声很难主导；
- mask 把“缺数据”显式标出，网络可以忽略；
- GRU 做时间平滑；
- actor 有 54/70 维本体/特权/速度可回退（flat 照走、bridge 停住）；
- 地形课程（stairs / rough / broken bridge）让 height latent 见过多种几何，泛化到新地形。

## 5. 边界（部署侧实验）

| 条件 | 结果 |
|---|---|
| Perlin 20% | 1/2 失败（s1 卡在 1.32 m） |
| Flying 10% | 2/2 通过但贴阈值（6.42 / 6.56 m） |
| Gaussian 0.15 m | 2/2 通过（6.88 / 6.65 m） |
| Vine 20% | 2/2 通过（8.11 / 7.75 m） |
| 外参 3°/2cm + 2× 噪声 | 0/4 |
| 3 个大块无效区域 | 0/4，只走约 1 m |
| 深度全无效 | flat 照走；bridge 停在缺口前 |

## 6. 未证明 / 后续

- 这是解释性判断，不是因果 ablation；
- 要证明：去 mask / 去 GRU / 改池化 / 去 DAgger / 去地形课程，各训一版对比；
- 若要提升：训练时加入外参随机化、大块 dropout、深度噪声；或加 mask 后的回退策略。
