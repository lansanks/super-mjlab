# SRMAV 教师阶段设计与实现

> 状态：教师阶段已实现。
>
> 更新时间：2026-10-23。
>
> 当前训练目标：Black 四列地形教师。

## 1. 目标

SRMAV 在 SRMA 教师-学生框架上拆分教师的外部信息编码，并加入新的地形课程：

- 教师高度信息使用 velocity 版本的中心 187 点扫描；
- 高度编码和摩擦/外力编码分成两个独立 latent；
- 真值速度不经过编码，直接进入 actor；
- 教师保持完全前馈，不使用 GRU；
- Black 使用包含楼梯、粗糙地面和断桥的四列课程；
- 第二阶段视觉学生使用 160×90 深度、25 FPS，并蒸馏同一教师。

## 2. 教师输入与网络

### 2.1 周围高度

使用现有的中心 `terrain_scan`：

```text
范围：1.6 m x 1.0 m
分辨率：0.1 m
点数：17 x 11 = 187
```

高度语义沿用 SRMA 教师，而不是 velocity critic 的相对躯干 clearance：

```text
z_ref = 当前有效接触脚对应地形高度的中位数
h_i = clip((hit_z_i - z_ref) / 0.15, -3, 3)
miss_i = 0
```

四脚全部腾空时沿用上一控制步的 `z_ref`。

高度编码器：

```text
187 -> 32 -> 16 -> LayerNorm
```

最终输出：

```text
l_h: 16-D height latent
```

### 2.2 特权信息

输入为：

```text
foot friction: 3
previous push velocity: 6
总计：9
```

摩擦为三个轴的共享足底摩擦。外力使用上一控制步、机体系的速度冲量，不是持续外力。

特权编码器：

```text
9 -> 32 -> 6 -> LayerNorm
```

最终输出：

```text
l_p: 6-D privilege latent
```

### 2.3 教师 actor

```text
[proprio(45), v_gt(3), l_h(16), l_p(6)]
= 70
```

actor MLP：

```text
70 -> 512 -> 256 -> 128 -> 12
```

速度 `v_gt` 始终直接进入 actor，不受外部模式消融影响，也不经过高度或特权编码器。

### 2.4 消融模式

`external_mode` 支持：

| 模式 | 高度分支 | 特权分支 |
| --- | --- | --- |
| `none` | 置零 | 置零 |
| `height` | 启用 | 置零 |
| `priv` | 置零 | 启用 |
| `full` | 启用 | 启用 |

## 3. Black 地形课程

地形生成器使用：

```text
patch 大小：8 m x 8 m
行数：10
列数：4
curriculum：开启
初始等级：0-5
```

四列分别为：

```text
stairs_up
stairs_down
random_rough
broken_bridge
```

### 3.1 楼梯

- 上行 `pyramid_stairs`
- 下行 `pyramid_stairs_inv`
- 高度范围均为 `0-25 cm`
- 随课程行插值

### 3.2 粗糙地面

使用 `random_rough` 默认设置：

```text
noise_range = (0.02, 0.10)
```

粗糙度固定，不随课程等级变化；课程等级变化只影响同列的地形行。

### 3.3 断桥

断桥沿世界 `+x` 方向铺设，桥面宽度等于整个地形列宽度。

当前参数：

```text
断口数量：4
断口宽度：0.10 -> 0.35 m
断口间平台：1.2 m
入口/出口平台：自动均分剩余长度
桥面厚度：0.1 m
坑深：1.0 m
```

断口和入口/出口平台共同覆盖整列长度，因此两端没有额外的可掉落坑面。

课程第 0 行缺口为 10 cm，第 9 行为 35 cm。同一 patch 内的四个断口使用同一课程宽度。

## 4. 断桥命令与出生

断桥环境从固定入口进入：

```text
世界 x 正向
世界 y 居中
yaw = 0
```

断桥专属命令：

```text
vx = 0.3-1.0 m/s
vy = 0
heading target = 0
omega_z = heading controller 输出
```

也就是只给前向速度，横向速度为 0，角速度只用于保持机头垂直断面。

楼梯和粗糙地面继续使用普通混合随机速度命令。

## 5. 子地形边界

训练时，每个环境只能在自己的 8 m x 8 m 子地形 patch 内活动。

边界终止条件根据：

```text
terrain_levels
terrain_types
terrain_generator.size
```

计算真实 patch 边界，而不是依赖环境出生原点。机器人中心越过边界约 0.1 m 时：

```text
out_of_sub_terrain_bounds
time_out = True
```

前方、后方、左侧和右侧越界都按时间截断处理，不作为失败终止。

play 模式不启用该边界终止，因此 Viser 中可以继续走出当前 patch。

## 6. 断桥奖励

### 6.1 状态

每个环境维护：

```text
current_gap_index   当前正在处理的断口
feet_rewarded       四只脚当前断口是否已经领奖
```

由于断口之间有 1.2 m 平台，四只脚全部通过当前断口前，不会进入下一断口的远端，因此不需要为每只脚维护独立 gap 序号。

### 6.2 单脚条件

对当前断口远端：

```text
foot_x > gap_far_x + 0.02 m
contact_found = True
contact_force >= 10 N
command_norm > 0.1
```

满足后：

- 该脚在当前断口只奖励一次；
- 内部事件奖励 `foot_bonus=2.5`；
- reward term 外部权重 `0.1`；
- 实际进入 PPO 的奖励为 `2.5 x 0.1 = 0.25`。

四只脚合计：

```text
4 x 0.25 = 1.0
```

### 6.3 切换断口

四只脚都完成当前断口：

```text
feet_rewarded.all()
-> current_gap_index += 1
-> feet_rewarded 清零
```

该奖励没有：

- 全桥完成奖励；
- 最终 `time_out` 成功奖励；
- 坑底高度判断；
- 机身中心过缝奖励。

一次性事件奖励会除以 `env.step_dt`，抵消 `RewardManager` 默认的 `dt` 缩放。

### 6.4 指标

```text
Metrics/bridge_gap_index
Metrics/bridge_feet_rewarded
```

## 7. 卡住惩罚

当前仍沿用 SRMA 的瞬时速度判据：

```text
progress_speed =
    dot(command_xy, actual_xy) / norm(command_xy)
```

`command_stall_penalty`：

```text
weight = 1.0
grace_time = 0.5 s
ramp_time = 1.0 s
penalty_start = 0.1
penalty_end = 0.5
```

`command_stall_reset`：

```text
reset_time = 2.5 s
```

注意：当前该判据仍基于瞬时速度。前后摆动可能短暂超过恢复速度并清零计时，尚未改成净位移判据。

## 9. 任务与训练

教师任务：

```text
Mjlab-SRMAV-Teacher-Rough-Black
```

任务名中的 `Rough` 是兼容旧 ID，实际使用本文件的四列地形。

从零训练：

```bash
uv run train Mjlab-SRMAV-Teacher-Rough-Black \
  --env.scene.num-envs 4096 \
  --agent.max-iterations 5000
```

本地续训：

```bash
uv run train Mjlab-SRMAV-Teacher-Rough-Black \
  --env.scene.num-envs 4096 \
  --agent.resume True \
  --agent.load-run <run_name> \
  --agent.load-checkpoint model_<iteration>.pt \
  --agent.max-iterations <additional_iterations>
```

`--agent.max-iterations` 表示本次新增迭代数，不是绝对最终迭代数。

## 10. Play

play 可以选择单个地形：

```text
--terrain-type stairs_up
--terrain-type stairs_down
--terrain-type random_rough
--terrain-type broken_bridge
```

示例：

```bash
uv run play Mjlab-SRMAV-Teacher-Rough-Black \
  --checkpoint-file <checkpoint.pt> \
  --viewer viser \
  --num-envs 1 \
  --terrain-type broken_bridge
```

不传 `--terrain-type` 时保持默认地形分配。

该参数要求任务使用 `curriculum=True` 的生成地形。play 中：

- 不启用子地形边界终止；
- 仍保留摔倒、非法接触等终止；
- 可选把 RGB-D 相机用于 Viser 调试。

## 11. 视觉学生

学生只使用可部署的本体观测和挂载在 `d435_link` 的深度相机：

```text
depth [B, 90, 160, 2]
  -> CNN
  -> visual GRU
  -> height_latent_hat [B, 16]

actor_obs [B, 45]
  -> proprio GRU
  -> privilege_latent_hat [B, 6]
  -> velocity_hat [B, 3]

actor input = [actor_obs, height_latent_hat,
               privilege_latent_hat, velocity_hat] = 70
```

深度两通道分别为归一到 `[0, 1]` 的 z-depth 和有效像素 mask。训练时每两个
50 Hz 控制步更新一次深度，即固定 25 FPS，不增加额外的控制步延迟。

三路估计值送入 actor 前全部 detach，因此动作损失只更新 actor；高度 latent、
特权 latent 和速度损失分别更新对应 GRU。DAgger 使用 1.0 到 0.2 的十等分
阶梯教师比例，每份下降 0.1。

## 12. Checkpoint 兼容性

以下旧教师 checkpoint 不兼容：

- 旧 SRMA 64 维教师 actor checkpoint；
- 旧 SRMAV 单 16 维融合 latent checkpoint。

原因是：

- 第一层 actor 从 64 维变为 70 维；
- 外部编码器由单一融合模块变为两个独立编码器；
- 学生接口从盲态单 GRU 变为深度视觉/本体双 GRU。
