# 学习笔记 · Learning robust perceptive locomotion for quadrupedal robots in the wild

Miki, Lee, Hwangbo, Wellhausen, Koltun, Hutter — Science Robotics 7(62), eabk2822 (2022)
ETH RSL + Intel · arXiv:2201.08117 · 本地：[2201.08117.pdf](2201.08117.pdf)

---

## 一句话

把"外感知在野外不可靠"当作**训练时的噪声分布问题**来解决：用循环信念编码器把本体感知与地形高度采样端到端融合，通过 privileged learning 让学生策略学会"视觉可信时预判、不可信时退回本体"，不需要任何规则或模式切换。

## 为什么值得读

野外外感知会以很多方式失效：雪/水的反射与无纹理、植被与软地形的 2.5D 表达失真、反光地面的离群点、遮挡造成的空洞、打滑造成的位姿漂移。既往方法要么假设地图准确（模型派），要么干脆不用视觉（纯本体派，速度被锁死）。本文要同时拿到视觉的**速度**和本体感知的**鲁棒性**。

## 方法骨架

**阶段一 · 教师**（PPO，RaiSim）
观测含特权信息（接触状态/力/法向、摩擦系数、外力力矩、腾空时间）。动作沿用 CPG 思路：每腿相位偏移 Δφ + 残余关节目标 Δq，经 IK 转为 12 个关节目标。教师不需要可部署，只作为行为上界。

**阶段二 · 学生**（监督蒸馏）
输入只有本体感知 + **加噪**的高度采样。两个损失：

- 行为克隆：对教师动作做平方误差；
- 重建：从信念还原"**干净**高度采样 + 特权信息"。

噪声模型不是随手加高斯：逐点 / 逐足（每步重采样 + 整回合固定）/ 离群点 / 逐区域偏移，并按时序工况抽样——正常 60%、大偏移 30%（模拟漂移与软地形）、大噪声 10%（模拟遮挡与建图失败），幅度随课程增长。

**阶段三 · 部署**
零样本，无微调。ANYmal C，20 Hz 机体重心高程图，50 Hz 策略，从图中采 208 个高度点。只保留 $g_e$、GRU、两个门、动作 MLP。

## 结构要点

| 记号 | 含义 | 维度 |
|---|---|---|
| $o^p$ | 本体感知 | — |
| $o^e$ | 高度采样（4 腿 × 52 点） | 208 |
| $l^e$ | 外感知 latent | 96 |
| $b'$ / $h$ | GRU 输出（中间信念） | 50 |
| $\alpha$ | 门 | 96（融合）/ 208（重建） |
| $b$ | 最终信念 | 120 |

**融合通路**：$b = g_b(h) + \alpha_{\text{fuse}} \odot l^e$。视觉以残差形式叠加在底座 $g_b(h)$ 上。$\alpha_{\text{fuse}} \to 0$ 时只剩底座。

**重建通路**：$\hat o^e = \mathrm{Dec}_e(h) + \alpha_{\text{rec}} \odot o^e$，$\hat s^{priv} = \mathrm{Dec}_p(h)$。

**两个门不是同一个**：融合门乘 96 维 latent，由行为克隆主导训练；重建门乘 208 维原始点，由重建损失主导训练。论文说 "the same gate" 指同一**机制**，不是共享权重。

## 我踩过的坑

| 当时的理解 | 实际 |
|---|---|
| 解码器吃脏外感知，重建干净图 | 主路只读 $h$；旁路喂的是被门控的**当前测量**，它是残差项 |
| $h_t$ 之外还有个 $b_t$ 进解码器 | 实现里解码器读的是 GRU 输出 $h$；正文把 $h$ 和 "belief state" 混着叫，计算图上它们是分开的 |
| $\alpha=0$ 就退化成纯本体策略 | **错**。$l^e$ 本来就是 GRU 输入，$b'$ 里有外感。$\alpha$ 是**增益**不是开关，调的是外感的带宽与新鲜度 |
| $b_t$ 分两路进两个编码器 | 分岔点是 $b'$；$\alpha$ 由 $b'$ 算出，否则循环定义 |
| 有一路"再编码一次地形" | 没有。地形那一路就是把 $l^e$ 原样拿来乘 $\alpha$——这正是"残差"的含义 |
| "底座"是为了升降维对齐 | 维度对齐只是必要条件。$g_b$ 是带隐层的非线性投影，负责给退化通路留表达能力 |
| 重建让 $h$ 里"包含"三类信息 | 是"**能读出**"。50 维装不下 258 个目标值，它是**充分统计量**，不是副本 |
| 门是被重建训练出来的 | 解码器的门是；**融合门主要靠行为克隆**，重建只是间接影响 |
| 目的是"对控制有用的三类值" | 还要加一个定语：**对控制有用、且被世界真值锚定**的状态估计 |

## 两个损失各训练谁

| 模块 | 行为克隆 | 重建 |
|---|---|---|
| 视觉编码器 $g_e$ | ✅ | ✅（挤过 50 维瓶颈） |
| GRU | ✅ | ✅ |
| 融合门（96 维） | ✅ | ❌ |
| $g_b$ | ✅ | ❌ |
| 动作 MLP | ✅ | ❌ |
| 三个解码器 MLP | ❌ | ✅ |
| 教师 | 冻结，仅提供目标 | — |
| 建图 / 位姿估计 | 不在计算图里 | — |

**分工**：重建负责让记忆里**有东西**，BC 负责让融合方式**好用**。

## 四个关键设计动机

**1. 重建目标必须是"干净真值"，不能是输入。**
否则退化成自编码器：抄一遍就能让损失归零，信仰向量什么也不用装。目标必须包含策略在真机上永远拿不到的量（干净地形、摩擦、接触），才有信息增益。

**2. 为什么是"相加"而不是直接输出绝对地形。**
加法的零点是"什么都不做"：门全开 + 修正量为零 = 抄测量；门全关 = 纯记忆重建。两个极端可达，中间连续。若直接回归 208 个绝对值，网络得先学会"测量大概是多少"才能开始学"哪里要改"。

**3. 50 维瓶颈本身就是正则。**
若 $h$ 有 1000 维，网络可以把扫描点原样背下来，重建损失照样归零，但学到的是记忆不是理解。窄瓶颈强迫它保留**可泛化的结构**（"前方 30 cm 有台阶"而非 208 个浮点数）。

**4. 重建权重 0.5 是容量分配旋钮。**
调大 → 偏向地形重建器，动作变糙；调小 → 变成机灵但不记事的策略。论文没解释这个数，但两条损失的张力决定了它只能是这个量级。

## 一个准确的刻画

$h_t$ 最终 ≈ 卡尔曼滤波的三件套：**状态估计**（地形与物理状态）、**不确定性**（有多确定）、**新息**（这步观测与预期差多少）。

这解释了它为何能同时支撑三件事：算门（需要不确定性与新息）、给修正量（需要新息）、给特权估计（需要状态估计）。三者本就是同一个估计器的三个输出。

**$\alpha$ 就是卡尔曼增益**：增益小不代表"不采信观测"，而是"这一步的观测相对先验权重低"。

## 自检版复述

> $b'$ 是 GRU 输出的、对历史做带惯性压缩的 50 维信念，必须同时装下：平滑版地形、接触界面的物理状态、以及"当前测量可不可信"的判断依据。
>
> 前两样由重建直接监督：解码器从 $b'$ 读出修正量与特权状态，加上被门控的当前测量，去逼近仿真真值。第三样是间接逼出来的——门要从 $b'$ 算，算不对则重建不准、动作也歪。
>
> 融合通路用另一个门：$b = g_b(b') + \alpha \odot l^e$，乘的是 96 维 latent。最终 actor 看到的是 $[o^p, b]$，本体感知直连，不过门。
>
> 一句话：重建负责让 $b'$ 里"有东西"，门负责决定"这一帧的东西怎么用"，二者共用同一个 50 维瓶颈。

## 实验与证据链

| 层级 | 实验 | 结论 | 强度 |
|---|---|---|---|
| 定性 | 野外部署（雪、植被、洞穴、湿滑楼梯） | 零摔倒，覆盖多种失效类型 | 弱（n=1，无分母） |
| 长时程 | Etzel 徒步 2.2 km / 爬升 120 m / 38% | 78 min（规划器 76 min），登顶 31 min（路牌 35 min） | 中（n=1 但难度难伪装） |
| 定量 | 台阶 12–36.5 cm，各 10 次 | 可靠通过 30.5 cm；基线 20 cm 开始崩；>32 cm 主动犹豫 | 中 |
| 定量 | 障碍赛道 | 33 s 自主 vs 基线 75 s 需人抬 | 中 |
| 定量 | 速度 | 1.2 vs 0.6 m/s；转向 3 vs 0.6 rad/s（5×） | 强 |
| 机理 | 信念可视化：软泡沫 / 透明板 / 遮传感器 / 光滑台 | 记忆、双向修正、无缝回退、可重新启用 | 中偏强（有循环论证风险） |
| 统计 | 仿真 41×41 参数网格，每格 300 次 | 可通行区域显著外扩，且超出训练分布 | 强（仿真内） |
| 归因 | 消融 GRU/MLP × 门/无门 | 循环必要；门主要贡献"视觉好时别浪费"，大噪声下与无门控持平 | 强 |
| 实战 | DARPA SubT，4 台，1700 m+ | 三类赛道零摔倒，决赛第一 | 中 |

**注意**：门控不是抗噪的功臣。鲁棒性主要来自噪声注入训练 + 循环滤波 + 重建约束；门的价值在"视觉可靠时用满"。

## 局限（作者自陈）

- 只隐式使用不确定性：悬崖边/踏脚石前，遮挡导致信息缺失时，策略假设地面连续，可能踩空；
- 高程图作为中间表示丢掉了材质与纹理信息；建图依赖未联合训练的经典位姿估计；
- 做不了与正常行走差太远的动作（腿卡窄洞、攀高台）。

## 顺带值得记的三件事

1. **失效建模优先于失效检测**：与其写规则判断"地图坏了"，不如把"坏"写进训练分布，让网络学出软增益。
2. **重建损失是给可部署部件做的训练期正则**：解码器是耗材，真正被塑造的是 $g_e$ + GRU。
3. **实验矩阵按"感知失效类型"组织，而不是按"地形类型"**：雪=反光、植被=软硬不分、洞穴=稀疏、透明=系统性说谎。这个组织方式比任何单个结果都更值得学。
