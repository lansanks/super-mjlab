## 2. T0：必读三篇

### 2.0 为什么是这三篇：同一个诊断，三种药方

SoloParkour 和 WMP 的引言在攻击同一个假设：**特权信息可以从传感器历史里被完整重建**。

SoloParkour 说得很直白：特权信息可能包含被遮挡的、视场外的、或因延迟而缺失的内容，所以"最优视觉策略"本来就不等于"模仿特权策略"——学生应该学会**在看不全的情况下做最优决策**，而不是尽量像 teacher。
WMP 说的是同一件事的另一面：teacher-student 的信息瓶颈让 student 达不到最优，而且"先有特权知识再走路"这件事本身就不像动物学习。

区别在药方：

- **SoloParkour**：保留 teacher，但只把它当**数据源**。学生用 off-policy RL 自己探索，critic 告诉它"在你看不到的地方，这个动作会怎样"。
- **WMP**：不要 teacher。让 world model 从观测里学一个**可预测的 latent**，策略在这个 latent 上学。
- **Parkour in the Wild**：保留多个 teacher（地形专家），蒸馏后**继续用 RL 微调**，让学生学出专家没教过的行为。

这一段本身就是三篇的"共同问题"笔记。建议读完先写这一页，再写单篇。

### 2.1 SoloParkour：Constrained RL for Visual Locomotion from Privileged Experience

- **出处**：Elliot Chane-Sane, Joseph Amigo, Thomas Flayols, Ludovic Righetti, Nicolas Mansard — **CoRL 2024**
- **链接**：[arXiv:2409.13678](https://arxiv.org/abs/2409.13678) · [项目页](https://gepetto.github.io/SoloParkour/)
- **输入**：深度图历史 + 本体；输出关节指令；真机 Solo-12

**方法骨架**

1. 把 parkour 写成**约束式 RL**：最大化敏捷（reward），同时用 cost 约束安全。约束用 **CaT（Constraints as Terminations）** 实现——把违反约束转成终止概率，而不是塞进 reward。
2. **Stage 1**：特权策略，观测是周围 heightmap scan + 附近悬浮物高度，PPO + CaT。它不需要可部署，只负责"如果看得见该怎么走"。
3. **Stage 2**：视觉策略（ConvNet + GRU + MLP），用 **DDPG 变体 + CaT**，同时从两个 replay buffer 采样：`D_online`（自己走的）和 `D_priv`（Stage 1 策略在仿真里滚出来的）。
4. 关键不是"蒸馏"，是**用特权经验热启动 off-policy RL**。学生仍然从像素出发、用自己的 critic 学，所以能针对传感器的真实限制调整行为，而不是硬拟合 teacher 的动作。

**和你已读的接口**

这是你那条线上**唯一一个 off-policy 的样本**。RMA/Miki 把学生当回归器，CTS 虽然也是 RL，但仍是 on-policy 并发；SoloParkour 把学生当成一个可以反复利用历史数据的 off-policy agent，teacher 只是它 replay buffer 里的一份离线数据。它引用的正是 offline-to-online RL（Efficient Online RL with Offline Data 那一类），所以你能看到"离线数据 + 在线探索"的配比问题被搬到了腿足上。

**盯什么**

1. **两个 buffer 的采样比**：`D_priv` 占多少？特权动作对 depth 策略来说是 off-distribution 的，critic 怎么不被带偏？
2. **CaT 的约束怎么定**：哪些量是 cost（碰撞、姿态、力矩、关节限位？），阈值怎么选，终止概率 `p_i^max` 的影响。约束式 RL 和 reward shaping 在腿足上到底差多少。
3. **为什么是 DDPG 而不是 PPO/SAC**：off-policy 的稳定性技巧（target network、延迟更新、n-step？），以及像素输入下的训练时间。
4. **学生有没有真的超过 teacher**：如果只是接近，那"信息瓶颈"的论证就还没被证实。看它和 supervised distillation baseline 的差距来自**样本效率**还是**最终性能**。
5. **特权策略的盲区**：heightmap scan 看不到悬垂/头顶，学生用 depth 能不能补？crawl 技能是怎么处理"teacher 也不会"的情况的。

**局限**

仍是仿真里的特权策略；约束和 reward 的工程量大；Solo-12 是小 robot，大四足/大负载的迁移未验证。

**一句话**：把 teacher 当数据源，不当标签源。

### 2.2 WMP：World Model-based Perception for Visual Legged Locomotion

- **出处**：Hang Lai, Jiahang Cao, Jiafeng Xu, Hongtao Wu, Yunfeng Lin, Tao Kong, Yong Yu, Weinan Zhang — **ICRA 2025**（SJTU + ByteDance）
- **链接**：[arXiv:2409.16784](https://arxiv.org/abs/2409.16784) · [项目页](https://wmp-loco.github.io/)
- **输入**：深度图 + 本体历史；输出关节指令

**方法骨架**

1. **RSSM world model**：后验 `q(z|h,o)`、先验 `p(z|h)`，重建 depth + proprio，加 KL。world model 的频率低于策略。
2. 策略输入是 world model 抽出的 **abstract description（latent）**，actor/critic 用 **PPO 在仿真里采数据**训练。
3. **重要细节**：论文明确说 **不用 world model 生成 rollout**——"sampling data in the simulator is efficient enough"。所以它省的**不是样本**，而是换了一个带预测性的表征。
4. 主张：纯仿真训的 world model 能预测真机轨迹（Figure 5，定性）；在 crawl/tilt 这类 scandots 表达不了的地形上超过 teacher-student。

**和你已读的接口**

你在 SuperMimic 笔记里把 world model 理解成"从 s0 预测一整条 MDP 链"。WMP 是**另一种用法**：world model 不 rollout，只当表征。这两个用法要分开记：

| 用法 | 代表 | 用途 |
| --- | --- | --- |
| world model 当模拟器 | Dreamer、SuperMimic | 在 latent 里 rollout，省真实交互 |
| world model 当表征 | **WMP**、DAWN、JEPLO | 用预测任务约束 latent，策略仍在仿真里学 |

**盯什么**

1. **"不用 world model 生成 rollout"这一点**：它到底省了什么？答案是"换表征 + 加预测性正则"，不是数据效率。别把它当 Dreamer 读。
2. **RSSM 的重建目标**：depth 和 proprio 都重建吗？depth 权重多大？latent 维度、KL 的 β、world model 与策略的频率比。
3. **和 teacher-student 的对比是否公平**：参数量、训练步数、观测历史长度是否对齐。
4. **"sim 训的 world model 能预测真机"的证据强度**：只有定性图？有没有定量指标？n 是多少？
5. **它到底赢在哪**：是鲁棒性（crawl/tilt）还是速度？如果只在少数地形赢，原因是什么。

**局限**

不是 MBRL 的数据效率故事；world model 仍在仿真训；重建 depth 可能把容量花在不可预测的细节上——DAWN 后来正是改这一点。

**一句话**：world model 在这里是"会预测的表征"，不是"想象中的模拟器"。

### 2.3 Parkour in the Wild：Multi-expert Distillation + RL Fine-tuning

- **出处**：Nikita Rudin, Junzhe He, Joshua Aurand, Marco Hutter — **IJRR 2026**（ETH RSL）
- **链接**：[arXiv:2505.11164](https://arxiv.org/abs/2505.11164)
- **输入**：4 个 depth camera + 本体；输出关节指令；真机 ANYmal D

**方法骨架**

1. **9 个地形专家**：每个专家单独用 RL 训，感知输入是 **elevation map**（特权感知）。
2. **DAgger 蒸馏**：9 个专家蒸成一个 policy，学生输入从 elevation map 换成 **depth images**；学生要用记忆补视场外。
3. **RL 微调**：蒸馏后在更广地形上继续用 RL 训（含真实 3D 扫描），不再有专家监督；还能反复微调加新技能。
4. 结果：ANYmal D 上部署；蒸馏后的策略甚至学会主动调整机身姿态，让障碍进入深度相机视场。

**和你已读的接口**

这是"特权感知 → 视觉学生"的**多教师版本**：Miki/AME 是一个 teacher，这里是 9 个地形专家；蒸馏之后再用 RL 微调，绕开"学生永远不如 teacher"的上限。它回答的是你那条线没覆盖的问题：**多个技能怎么合成一个视觉策略，合成之后怎么继续变强**。

**盯什么**

1. 9 个专家怎么划分地形；专家之间怎么避免重叠。
2. DAgger 的 query 策略与聚合；蒸馏时 depth 噪声怎么加（§2.4）。
3. RL 微调会不会破坏专家技能（灾难遗忘）；微调时地形分布怎么扩。
4. "主动感知"行为是 emergent 的还是 reward 引导的。
5. 真实 3D 扫描怎么进仿真（mesh？）。

**局限**

工程重；专家设计靠人；IJRR 版比 arXiv 版多了什么，值得对照。

**一句话**：先把技能分开学，再蒸成一个视觉策略，最后用 RL 学出专家没教过的行为。

## 3. T1：按缺口选读

### 3.1 表征：地图的反面

#### PointWalker：Mapless Quadruped Locomotion Directly From Raw LiDAR Point Clouds

- [arXiv:2610.15548](https://arxiv.org/abs/2610.15548)（RA-L 投稿，2026-10）
- **做法**：4 个 LiDAR 的原始点云 → 体素化 → linear self-attention → 与本体做 cross-attention；**不要地图、不要 foothold 估计**；一次 PPO 训 7 类地形。
- **结果**：仿真 90.1% 成功率；真机 X30 板载 50 Hz，0.8 m 沟、0.8 m 台、45° 钢格栅楼梯、50 kg 负载、2.5 km 山路。
- **为什么读**：你下载了但还没读的 AME/AME-2 是 map-centric 的顶点；这篇是反命题。地图的三个软肋（里程计漂移、维护成本、格栅/透明物被骗）它都拿来当动机。
- **盯什么**：体素分辨率与感受野；linear attention 的复杂度；4 个 LiDAR 的外参/时间同步；**see-through grating 的双通道仿真**（LiDAR 会穿过格栅，这是 map/depth 都容易骗过的 case）；50 Hz 的板载算力预算。
- **局限**：4 LiDAR 是硬件假设；点云 sim2real 比 depth 容易，但标定和同步是工程难点。

#### JEPLO：Joint-Embedding Predictive Learning for LiDAR-Based Legged Locomotion

- [arXiv:2609.15770](https://arxiv.org/abs/2609.15770)（2026-09，开源）
- **做法**：PE-JEPA（proprio-exteroceptive JEPA）学预测式自监督表征，再用 **CJTS**（concurrent JEPA-teacher-student）训策略；LiDAR、map-free、单阶段。
- **为什么读**：它把 world model 从"重建"推向"**预测表征**"，和 DAWN 的重建路线形成对照。三篇正好是一条光谱：

| 表征路线 | 预测目标 | 代表 |
| --- | --- | --- |
| 重建观测 | depth / proprio | WMP |
| 去噪重建 | clean depth | DAWN |
| 预测 latent | 未来 embedding | **JEPLO** |

- **盯什么**：JEPA 预测的是未来 latent 还是当前观测的 embedding；怎么防 collapse（stop-grad / EMA / variance regularizer）；LiDAR 稀疏性怎么编码；CJTS 与 CTS 的差别；开源代码能不能跑。
- **局限**：JEPA 在腿足上的证据还少；LiDAR 硬件假设；表征的可解释性弱于地图。

### 3.2 监督：世界模型

#### DAWN：Noise-Robust Quadruped Parkour via Depth-Denoising World Models

- [arXiv:2609.29092](https://arxiv.org/abs/2609.29092)（**IROS 2026**）
- **做法**：把 noisy depth 喂 encoder，**clean depth 做重建目标**，再加 noisy/clean latent 的对比对齐；不需要手工滤波；Go1 zero-shot，18 cm 台阶、70 cm 沟、45 cm 高台。
- **为什么读**：WMP 的重建目标有个隐含问题——depth 里本来就有噪声和不可预测的细节，重建它们会浪费容量。DAWN 把"去噪"变成显式目标，是 WMP 线的自然下一步。也直接对应你笔记里"仿真深度太干净"那条坑。
- **盯什么**：训练时噪声怎么造（仿真 depth 加什么模型）；对比学习的正负样本；"无手工滤波"的代价（训练时长/数据量）；真机三种地形的定量与失败率。
- **局限**：噪声仍是 sim 定义的；"zero-shot"指不调滤波参数，不是跨机器人。

### 3.3 真机监督：仍然独特的一条

#### CMS：Learning Visual Locomotion with Cross-Modal Supervision

- [arXiv:2211.03785](https://arxiv.org/abs/2211.03785)（**ICRA 2023**，你清单里已有，保留）
- **做法**：仿真训 blind policy → 真机上训视觉模块，监督信号是**时间偏移后的本体感觉**；融合后部署。30 分钟真机数据，19 cm 台阶、35° 湿滑坡、20 cm 台阶。
- **为什么读**：唯一一条"完全不在仿真里训视觉"的路线。和 SoloParkour 的"仿真里 off-policy 学视觉"是两端；两条都读完，你对"视觉在哪学"就有完整的坐标系。
- **盯什么**：偏移多少帧；视觉模块输出 latent 还是 depth；相机偏移实验说明学到几何还是过拟合；30 分钟覆盖了什么、没覆盖什么。

### 3.4 信任：架构层面的另一种解法

#### KiVi：Kinesthetic-Visuospatial Integration

- [arXiv:2509.23650](https://arxiv.org/abs/2509.23650)（2025-09）
- **做法**：把本体（kinesthetic）和视觉（visuospatial）**分成两条通路**，本体当稳定 backbone，视觉选择性注入；memory-enhanced attention；对 OOD 视觉噪声和遮挡鲁棒。
- **为什么读**：Miki 是"融合 + 学 gate"，KiVi 是"**分离 + 选择性注入**"。这是架构层面的信任机制，和 Miki 的学习门、REDACT 的统计门（备选）构成三种解法。
- **盯什么**：分离是双 encoder 还是双 policy；融合点在哪；OOD 测试怎么定义；和 REDACT 的 gate（备选）对比谁更省。

#### RENet：Redundant Estimator Networks under Visual Collapse

- [arXiv:2509.09283](https://arxiv.org/abs/2509.09283)（**RA-L**）
- **做法**：双估计器 + 在线自适应，视觉崩溃时切换；工程味重。
- **为什么读**："检测-切换"路线的代表，一页足够，不必精读。知道有这条路即可。

### 3.5 语义：几何之外的下一个轴

#### SABER：Attention-based Semantic Affordance

- [arXiv:2609.21572](https://arxiv.org/abs/2609.21572)（2026-09）
- **做法**：terrain-affordance map，每格存几何 + **语义接触代价**；attention logit 上加 signed semantic bias，按"到最近脚的距离"门控；B2 真机；去掉语义 bias，forbidden contact +55%。
- **为什么读**：几何可通行 ≠ 应该踩。工业/室内场景会先遇到这个问题；它也是"感知不只是几何"的一个具体入口。
- **盯什么**：语义标签从哪来；cost 怎么进 reward/约束；距离门控的动机；真机四类语义障碍的覆盖。

### 3.6 系统：感知放在哪一层

#### ANYmal Parkour：Learning Agile Navigation for Quadrupedal Robots

- [arXiv:2306.14874](https://arxiv.org/abs/2306.14874)（**Science Robotics 2024**，Hoeller, Rudin, Sako, Hutter）
- **做法**：先训多类障碍技能（走、跳、爬、蹲），再训高层导航策略在技能间选择；感知模块从**高度遮挡、噪声大**的传感数据里重建障碍，给高层做 scene understanding。全仿真训练，真机 2 m/s 连续过障碍。
- **为什么读**：它把"感知"拆成两层：低层技能不需要地图，高层的 scene understanding 才需要。这和你还没读的 AME-2 那种"感知直接进策略"是两种系统架构；也补上 Miki 的盲区（遮挡/视场外）在系统层的解法。读完它，ViNL 可以跳过。
- **盯什么**：技能怎么定义和终止；高层观测里有多少是感知、多少是技能可行性；感知重建模块的监督信号；遮挡/噪声怎么建模。
- **一句话**：感知不必都进低层；高层只需要"哪里有障碍、哪个技能能过"。

## 4. T2：工程落地，两篇就够

### 4.1 elmap-rl-controller：资源受限四足的外感管线

- [arXiv:2505.12537](https://arxiv.org/abs/2505.12537)（**ICRA 2025**，ETH-PBL，开源）
- **做法**：实时高程图 + **同时训 policy 和 state estimator**（后者给高程图提供里程计，可选融 VIO）；额外加一个 ToF 传感器，没 VIO 也能稳；17.5 cm 台阶，22.5 cm 台阶 80% 成功率。
- **为什么读**：这是"深度 → 高程图 → 策略"最省时间的工程模板，代码开源。你要在 mjlab/Go2 上搭管线，先照它抄接口，比从 Miki 的论文里猜实现快得多。
- **盯什么**：高程图分辨率/更新频率；state estimator 和 policy 怎么联合训；ToF 装在哪、为什么能替代 VIO；代码的仿真接口能不能换成 mjlab。

### 4.2 PPL：感知只在训练期用的第二种用法

- [arXiv:2508.09950](https://arxiv.org/abs/2508.09950)（**RA-L**）
- **做法**：用点云监督一个 **proprioceptive state estimator**，估计碰撞状态 + 地面/空间特征（极坐标表示 + MLP）；部署时**不用外感**；专治 crawl space。
- **为什么读**：你熟悉"用特权信息蒸馏动作"；这篇是"用感知**蒸馏状态估计**"。没有外感、或外感不可靠的平台，这是另一条路。
- **盯什么**：点云特征怎么监督（对比/回归）；极坐标为什么高效；碰撞状态怎么定义；和 DreamWaQ/HIM 的"隐式估计"差别在哪。

## 8. 读任何一篇都问的五个问题

1. **特权信息是什么？** 学生实际能看到什么？信息瓶颈在哪？
2. **监督信号从哪来？** BC / 重建 / critic / 自监督 / world model？
3. **失效怎么处理？** 建模、检测、还是架构隔离？训练分布外怎么办？
4. **表征是什么？** map / pixel / point / latent？记忆放在哪？频率怎么对齐？
5. **真机证据强度？** n=1 视频 / 定量 / 多地形 / 统计？基线是否包含 teacher-student？
